# Hyprland window contract on November 22, 2026

The native test ran on CachyOS with Hyprland 0.57.0
(`0aa6745f70`). X's test code was built from
`140809183b81364d7c4e9738a1cfca0070b0d637` and controlled a temporary
Foot window identified by its process ID and a unique app ID.

```sh
cargo test --locked -p x-agent --lib wm::tests::live_hyprland -- --ignored --exact --nocapture
```

One test passed. It verified focus, moving the fixture and undoing the
move, switching workspaces and returning, maximizing and restoring,
minimizing and restoring, and closing the fixture. The same case confirmed
that a mismatched process ID cannot move the window and that its old
identity cannot receive focus after it closes.

Fresh installation, microphone capture, global shortcuts, and the full
release checklist remain pending.
